# Визитка Никиты: пакет для агентов

Новая визитка для `Sorakiel/sorakiel.github.io`, собирается точь-в-точь по эталону.

- **`DISPATCHER.md`** - для Диспетчера: сигнал старта «Начинай визитку», распределение задач, зоны файлов, приёмка, что нести Никите.
- **`SPEC.md`** - спецификация для исполнителей: всё о виде и поведении сайта, инспекторе, адаптиве, тестах и плане из 8 PR.
- **`reference/`** - эталон и материалы:
  - `portfolio.html` - весь сайт одним файлом, открыть в Chromium;
  - `src/` - CSS, JS и разметка эталона по отдельности;
  - `data/projects.ts` - данные проектов, готовые к переносу;
  - `assets/shots/` - 15 скриншотов проектов в webp;
  - `img/` - 67 скриншотов эталона: 1440×900 и 390×844, светлая и тёмная тема;
  - `video/` - запись десктопа (56 с) и телефона (25 с).

Как отдать в работу: положить папку рядом с проектами и отправить Диспетчеру `DISPATCHER.md`. Работа начнётся по сообщению «Начинай визитку».
