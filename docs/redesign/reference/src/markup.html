    Almanac

    Собственный продукт: модульное приложение для самодисциплины. Ядро - экран «Сегодня» и прогресс, а привычки, тренировки, чтение, фокус и рефлексия подключаются как отдельные модули. Пользователь сам включает нужные и задаёт их порядок. Один код на React работает в браузере, на Android и на компьютере.

    с июля 2026 · v0.6 · React 19 · TypeScript · Supabase · TanStack Query · Capacitor · Tauri
    300+коммитов с июля 2026, всё сделано одним человеком
    140+pull request'ов, каждый проходит линтер, типы и тесты в CI
    7модулей на общем ядре: включаются, выключаются и переставляются в настройках
    17e2e-сценариев Playwright в CI, плюс 46 файлов unit-тестов

    Офлайн без потерь

    Отметка видна сразу. Без сети запись ждёт в очереди, переживает перезапуск и уходит, когда связь вернулась. Если сервер отказал, изменение откатывается.

    offlineMutations.tsoffline-writes.spec.ts

    Приватность в базе

    Каждый видит только свои данные, даже если запрос из интерфейса ошибётся: это проверяет сам Postgres. 91 политика доступа.

    0001_init.sql

    Parkovich

    Сервис поиска свободных парковочных мест для «умного города». Делаю фронтенд целиком: веб-приложение с картой, сайт и письма.

    май 2025 - сейчас · React 19 · TypeScript · Vite · React Router · Ant Design · Docker · nginx
    1,5года во фронтенде сервиса, с мая 2025
    2продукта: веб-приложение на parkovich.ru/app и сайт с мобильными версиями
    5навигаторов для маршрута: Яндекс Карты и Навигатор, Google, 2ГИС, Apple
    100+моих коммитов в веб-приложении, сайте и шаблоне письма

    Своя карта парковки

    Зоны и ряды мест рисуются по координатам из API собственным SVG-рендером, без картографических библиотек. Зум колесом и щипком, карта не уезжает за границы.

    Живые статусы

    Свободные места обновляются каждые 5 секунд, у парковки есть график занятости и время последнего обновления.

    Продуктовая аналитика

    События открытия карты, показа мест, маршрутов и ошибок загрузки уходят на бэкенд, чтобы команда видела, как сервисом пользуются.
