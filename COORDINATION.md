База для всех PR - ветка `redesign`. `main` и `gh-pages` - живой сайт, не трогать до «да» Никиты.

### Правила

Conventional Commits, описание PR на русском, без упоминаний ИИ. К каждому PR - скриншоты рядом с эталоном (1440×900 и 390×844, светлая и тёмная) и запись для всего, что двигается.
