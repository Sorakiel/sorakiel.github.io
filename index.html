  1. О проекте
    Мой собственный продукт - модульное приложение для самодисциплины. Ядро - экран «Сегодня» и прогресс, к нему подключаются модули: привычки, тренировки, чтение, фокус, рефлексия, друзья, достижения. Работает в браузере, на Android и на компьютере.
    Задачи
    • Собрать разные инструменты в одно приложение так, чтобы оно не превратилось в свалку функций
    • Отметка привычки срабатывает за один тап, даже без сети, и ничего не теряется
    • Чужие данные закрыты на уровне базы, а не только интерфейса
    • Один код на три платформы, обновления без переустановки
    • Частые релизы не ломают то, что уже работает
    Что сделал
    • Модульную архитектуру: каждый модуль - отдельная фича со своим API и хуками, его можно включить, выключить и переставить, настройки синхронизируются между устройствами
    • Дизайн-систему с двумя темами, общую для всех модулей
    • Офлайн на TanStack Query: оптимистичные обновления, кэш на 7 дней, очередь записей, которая досылается, когда сеть вернулась
    • Схему в Supabase и 91 политику доступа RLS
    • Сборки под Android на Capacitor и под десктоп на Tauri
    • CI: 140+ PR через проверки, 17 e2e-тестов на Playwright и 46 unit-тестов на Vitest
    • Лэндинг продукта
    Ключевое
    Полный цикл продукта в одиночку: модульная архитектура, дизайн-система, база, сборки и тесты. Офлайн-режим, в котором не теряется ни одна запись.

  2. О проекте
    Сервис для водителей: на схеме парковки видно, какие места свободны прямо сейчас и сколько из них платных, бесплатных и для людей с инвалидностью. Веду весь фронтенд: веб-приложение и сайт.
    Задачи
    • Показать живую схему парковки по местам, а не просто точку на карте
    • Держать статусы свежими и честно показывать, насколько они свежие
    • Вход без пароля и сессия, которая не обрывается посреди поездки
    • Понять, как люди на самом деле пользуются сервисом
    Что сделал
    • Свою отрисовку парковки на SVG: по координатам рядов считаю прямоугольники мест, рисую зоны и маркеры с заполненностью, зум, фильтры по типу места, кэш отрисовки
    • Автообновление статусов и индикатор свежести данных: зелёный, жёлтый, красный
    • Поиск с подсказками, выбор адреса, избранное, маршрут в 5 навигаторов, поддержку и жалобы
    • Вход по коду, обновление токена до его истечения, отпечаток устройства
    • Продуктовую аналитику: 9 событий от открытия приложения до сбоев, с платформой и анонимным id
    • Сайт с мобильными версиями разделов, шаблон письма, сборку в Docker и nginx
    Ключевое
    Сложный интерфейс без готовой библиотеки: своя геометрия и отрисовка схемы, которая быстро работает на телефоне. Продуктовые метрики встроены в само приложение.

Almanac

Собственный продукт: модульное приложение для самодисциплины. Ядро - экран «Сегодня» и прогресс, а привычки, тренировки, чтение, фокус и рефлексия подключаются как отдельные модули. Пользователь сам включает нужные и задаёт их порядок. Один код на React работает в браузере, на Android и на компьютере.

Своя карта парковки

Зоны и ряды мест рисуются по координатам из API собственным SVG-рендером, без картографических библиотек. Зум колесом и щипком, карта не уезжает за границы.

Живые статусы

Свободные места обновляются каждые 5 секунд, у парковки есть график занятости и время последнего обновления.

Продуктовая аналитика

События открытия карты, показа мест, маршрутов и ошибок загрузки уходят на бэкенд, чтобы команда видела, как сервисом пользуются.
